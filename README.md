# 瑪麗安助手 MarianHelper

![瑪麗安助手](app/src/main/res/drawable-nodpi/marian_cover.webp)

用無障礙服務自動推《勝利女神：妮姬》主線章節的 Android 工具。


- 截圖：`AccessibilityService.takeScreenshot()`（需 Android 11 以上）
- 點擊／滑動／雙指縮放：`dispatchGesture()`
- 文字辨識：ML Kit 中文 OCR（SKIP、點擊任意處、進入戰鬥、快速戰鬥、OPERATION FAILED）
- 地圖辨識：顏色＋形狀（青藍菱形驚嘆號、紅色橢圓光圈）
- 介面：Jetpack Compose Material 3（支援動態配色、深色模式）

## 用 GitHub 編譯 APK

1. 在 GitHub 建立新的 repository，把這個資料夾全部上傳。
2. 推送後 Actions 會自動執行「Build APK」（也可以在 Actions 頁手動按 Run workflow）。
3. 完成後到該次執行頁面最下方 Artifacts，下載 `MarianHelper-v版本號`，解壓後安裝 APK。

## 使用方式

1. 開啟 App → 「前往設定」→ 無障礙 → 開啟「瑪麗安助手 MarianHelper」。
2. 允許通知（戰鬥失敗時通知用）。
3. 畫面上會出現瑪麗安頭像的 HUD 圓鈕：點一下展開控制面板，再點一下收起；可拖曳，放開後貼齊左右邊緣；長按或點面板的 X 關閉。
4. 到章節大地圖後，在面板按「開始推圖」。面板會顯示目前判斷的畫面和動作。
5. HUD 關閉後，可從 App 首頁開關或快速設定面板的「瑪麗安 HUD」重新打開。

## 判斷流程

| 畫面 | 判斷依據 | 動作 |
|---|---|---|
| 戰鬥失敗 | OCR：FAILED／重新挑戰 | 停止腳本＋通知（含關卡編號） |
| 劇情 | OCR：右上角 SKIP | 點 SKIP |
| 結算／解鎖 | OCR：點擊任意處／點擊繼續 | 點畫面下方中央 |
| 出擊準備 | OCR：進入戰鬥 | 快速戰鬥是橘色就點它，否則點進入戰鬥 |
| 大地圖 | OCR：CURRENT AREA／野外 | 見下方 |
| 其他 | — | 視為戰鬥中，等待 |

大地圖：

1. 找青藍色驚嘆號（主線）。下方有紅圈怪 → 點怪；沒有 → 點驚嘆號跳視角。
2. 隊伍到目標的路線上有紅圈怪 → 先打它。
3. 連續 3 次點同一個目標都沒動 → 視為被擋，先打最近的紅圈怪。
4. 橘色驚嘆號（支線）一律忽略。
5. 都找不到 → 縮小視角一次，再依序上下左右滑動探路。

## 程式結構

```
app/src/main/java/com/nikkeauto/
  MainActivity.kt   設定頁（Material 3）
  AutoService.kt    無障礙服務：截圖、手勢、懸浮窗、通知
  Bot.kt            狀態機與決策邏輯
  Screen.kt         OCR 與畫面分類
  Vision.kt         地圖顏色辨識（驚嘆號、紅圈、擋路判斷）
  Prefs.kt          開關與參數
```

## 版本紀錄

### v1.0.0（第一版正式版）
- 正式命名為「瑪麗安助手 MarianHelper」，新增 App 圖示與首頁封面。
- Material 3 懸浮 HUD：瑪麗安頭像圓鈕，點一下展開、再點收起，可拖曳貼邊，常駐顯示、可手動關閉。
- 劇情 SKIP（含跳過教學確認）、結算／章節完成、章節清單自動關閉。
- 大地圖：主線藍色驚嘆號優先、擋路紅圈怪先打、自動關小地圖、探路。
- 出擊準備：可用時點快速戰鬥，否則進入戰鬥；只在野外自動戰鬥。
- 任務箭頭換區、前哨基地指揮中心與方舟設施的劇情。
- 戰鬥失敗、被門擋住、探路找不到目標時停止並通知。

## 已知限制

- 顏色門檻是用 1080×2412 的截圖校正的，不同章節的光線（雪地、夜景）可能要微調 `Vision.kt` 的 `classify()`。
- 「我方隊伍位置」暫時假設在畫面正中央。
- 戰鬥中依賴遊戲內建的自動戰鬥。
- HUD 所在位置的點擊可能會被擋住，必要時把它拖到角落。

⚠️ 自動化腳本可能違反遊戲服務條款，有封號風險，建議先用小號測試。
