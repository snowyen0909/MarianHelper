# 瑪麗安助手 MarianHelper

![瑪麗安助手](app/src/main/res/drawable-nodpi/marian_cover.webp)

《勝利女神：妮姬》的 Android 自動化小幫手。用無障礙服務看畫面、點按鈕，幫你**推主線**和**跑每日任務**，不需要 Root、不需要電腦。

> ⚠️ 自動化腳本可能違反遊戲服務條款，有封號風險，建議先用小號測試。

## 下載

- **正式版**：到 [Releases](../../releases) 下載最新的 `MarianHelper-v版本號.apk`。
- **測試版**：版號結尾有 `b`（例如 `2.2.2b`），在 [Actions](../../actions) 最新一次「Build APK」的 Artifacts 下載。測試版功能較新，但可能還不穩定。
- 需要 **Android 11 以上**。

## 功能介紹

### 🗺️ 自動推主線

在章節大地圖按「開始推圖」，助手會一路往主線目標前進：

| 功能 | 說明 |
|---|---|
| 跳過劇情與結算 | 自動點 SKIP、確認跳過，以及「點擊任意處」繼續 |
| 大地圖自動尋敵 | 青藍色驚嘆號（主線）優先；路線上擋路的紅圈怪會先打 |
| 出擊準備自動點擊 | 快速戰鬥能用就點，否則點進入戰鬥 |
| 地圖巡弋探路 | 找不到目標時縮小視角，再上下左右滑動找路 |
| 只打主線目標 | 關閉後，沒有主線目標時也會打一般紅圈怪 |
| 其他自動處理 | 自動關小地圖、章節清單、依任務箭頭換區 |
| 戰鬥失敗 | 立刻停止並發通知（附關卡編號） |

橘色驚嘆號（支線）一律忽略。以上每一項都可以在「基礎功能」頁單獨開關。

### 📅 一鍵日常

按一次就自動打開遊戲、登入、依序做完每日任務：

| 項目 | 內容 |
|---|---|
| 登入遊戲（基礎） | 打開妮姬、點 TOUCH TO CONTINUE、關閉公告／活動／回歸彈窗 |
| 郵件 | 全部領取 |
| 前哨基地防禦 | 領掛機獎勵＋免費的一舉殲滅 |
| 派遣 | 全部領取＋全部派遣 |
| 好友 | 收送好友點數 |
| 付費商店 | 領每日免費禮包 |
| 普通商店 | 拿免費物品 |
| 妮姬升級 | 升級一次再等級重置 |
| 競技場 | 新人競技場；有比自己戰力低的就打他，沒有就打第 3 位。場數可調（預設 2） |
| 無盡之塔 | 依星期打當天開放的企業塔，每座最多 3 次（可調），打輸就停止 |
| 攔截戰 | 普通（LEVEL D／S／特殊目標）或異常個體（5 隻 Boss 可選）；快速戰鬥能用就用；每天 3 次共用，次數可調 |
| 每日任務 | 全部領取兩次 |

- 每一項都能**開關**、**長按拖曳排序**、按 **▶ 單獨測試**。
- 中途被打斷，再按一次會**接著做**沒完成的項目（每天 04:00 換日，與遊戲相同）。
- 商店與一舉殲滅**只拿免費的**，購買前會確認消耗為 0。
- 攔截戰點清單上的 ⚙️ 小齒輪可設定模式、目標、Boss 與次數。

### ⏰ 定時自動執行

在「設定」頁設定時間，每天時間到會自動喚醒螢幕、打開遊戲跑一鍵日常（需允許精確鬧鐘權限；手機重開機後仍有效）。執行中會保持螢幕亮著。

> 手機若有螢幕密碼，鎖定時無法自動解鎖，建議定時時段不要上鎖或改用滑動解鎖。

### 🎛️ 懸浮 HUD

- 遊戲畫面上的圓鈕：點一下展開控制面板，可直接開始／停止推圖或一鍵日常。
- 可拖曳，放開後貼齊左右邊緣；面板的 X 收起面板，**長按圓鈕**隱藏 HUD。
- 隱藏後可從 App 首頁或快速設定面板的「瑪麗安 HUD」重新打開。
- 設定中可開啟「開始時自動開 HUD」。

### 📝 日誌

首頁即時顯示每一步動作。設定頁可調整：顯示時間、只記重要事件、失敗時存截圖、分享日誌（回報問題時很好用）。

## 使用方式

1. 安裝 APK，開啟 App → 「無障礙權限設定」→ 開啟「瑪麗安助手 MarianHelper」。
2. 允許通知（戰鬥失敗、執行完成時通知用）。
3. **推主線**：進到章節大地圖，在 HUD 或 App 首頁按「開始推圖」。
4. **一鍵日常**：到「日常」頁勾選要做的項目並排好順序，按「一鍵日常」，App 會自動切到遊戲開始執行。
5. 要停止時按 HUD 上的停止；離開遊戲超過 8 秒也會自動停止。

## 運作原理

| 技術 | 用途 |
|---|---|
| `AccessibilityService.takeScreenshot()` | 截取遊戲畫面 |
| `dispatchGesture()` | 點擊、滑動、雙指縮放 |
| ML Kit 中文 OCR | 讀按鈕與標題文字（SKIP、進入戰鬥、剩餘次數…） |
| 圖片比對（NCC 模板比對） | 找沒有文字或字型難讀的圖示（信封、任務圓鈕、塔徽章、彈窗 X…） |
| 顏色辨識 | 地圖上的驚嘆號與紅圈怪、按鈕是否可按（橘色／灰色） |
| Jetpack Compose Material 3 | App 介面與 HUD，支援動態配色與深色模式 |

所有辨識與判斷都在手機上完成，不會上傳畫面或收集資料。

## 程式結構

```
app/src/main/java/com/nikkeauto/
  MainActivity.kt      App 介面（首頁／基礎功能／日常／設定）
  DailyUi.kt           日常清單、拖曳排序、攔截戰設定頁
  AutoService.kt       無障礙服務：截圖、手勢、啟動流程、日誌、通知
  Hud.kt               懸浮 HUD
  OverlayTileService.kt 快速設定面板的 HUD 開關
  Bot.kt               推主線的狀態機與決策
  Daily.kt             一鍵日常各項流程
  Schedule.kt          定時執行（鬧鐘、開機後重設、喚醒螢幕）
  Screen.kt            OCR 與畫面分類
  Vision.kt            顏色辨識
  Templates.kt         圖片比對
  Prefs.kt             設定值
app/src/main/assets/templates/   圖片比對用的樣本圖
```

## 自己編譯

1. Fork 這個 repository。
2. 推送後 Actions 會自動執行「Build APK」（也可以在 Actions 頁手動按 Run workflow）。
3. 完成後在該次執行頁面最下方的 Artifacts 下載 APK。
4. 若要固定簽章，在 repository 的 Secrets 設定 `KEYSTORE_BASE64`（keystore 檔的 base64）和 `KEYSTORE_PASSWORD`；沒設定時會產生 debug 版（每次簽章不同，更新要先解除安裝）。

## 已知限制

- 顏色與位置是用 1080 寬的畫面校正的，特殊比例的螢幕或某些章節光線（雪地、夜景）可能辨識較差。
- 戰鬥本身依賴遊戲內建的自動戰鬥。
- HUD 所在位置的點擊可能會被擋住，必要時把它拖到角落。
- 遊戲改版更動介面後，部分步驟可能需要更新。
